# Booth Navi

イベント会場でサークル名や頒布物を検索し、目当てのブースを地図で探せるWebアプリです。行きたいブースはお気に入りに、回ったブースは訪問済みにできます。

[会場マップを開く](https://roki0i.github.io/booth-navi/)

## 会場マップを使う

サンプルには架空のブースが24件あります。ブース番号、サークル名、頒布物名のいずれかで検索し、結果を選ぶと場所と詳細を確認できます。お気に入りと訪問済みはイベントごとに保存されます。

自分の会場図を使うには、編集モードでイベントを作成し、マップ画像を選びます。空いている場所をクリックしてブースを追加し、ドラッグで位置を調整します。複数のブースはShift＋クリックで選んで整列できます。画像を使わない場合、装飾背景の内側では追加が反応しないため、外周の余白から追加してください。

## データの読み込みと保存

- ブースをまとめて登録するときは、編集画面でCSVテンプレートを保存して記入し、UTF-8で読み込みます。プレビューを確認してから追加・置き換えを選べます。
- ロゴ、会場図、お品書きには、利用権限のあるPNG・JPEG・WebPを使ってください。
- イベントとブースはブラウザに自動保存されます。別端末へ移すには編集画面の「データ入出力」から**画像付きJSON**を書き出し、移行先で読み込みます。従来の画像なしJSONも読み込めます。
- 画像付きバックアップはロゴ・会場図・背景・お品書きの画像データを含みます。画像が欠けている場合は、欠損したバックアップを黙って作成せずエラーを表示します。1画像20MB・画像合計64MB・読み込みファイル96MB以内です。
- サイトデータを消すと保存内容も消えます。複数タブで他のタブの変更を検出した場合は自動保存を止め、現タブのJSON退避と再読み込みを案内します。同時書き込みの完全な排他制御や共同編集、編集イベントの公開URL発行には対応していません。

## ローカルで起動する

Node.js 24とnpmを使います。

```sh
npm ci
npm run dev
```

## テストとビルド

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

E2Eテストはビルド済みの `dist/` をポート4173で開きます。Linuxでブラウザの依存パッケージが必要な場合は `npx playwright install --with-deps chromium` を使ってください。

[GitHub Pagesへのデプロイ](.github/workflows/deploy-pages.yml)は `main` へのpushまたは手動実行で起動します。
