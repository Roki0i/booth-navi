# Booth Navi

ブース番号やサークル名から目的のブースを検索し、会場マップ上の位置と頒布情報を確認できる、モバイルファーストの静的 Web アプリです。

公開予定 URL: <https://roki0i.github.io/booth-navi/>

## 制作背景

小規模な同人・展示イベントでは、スプレッドシートや PDF、画像形式の会場図が使われることがあります。スマートフォン上で目的のブースを探しにくい課題を、検索とインタラクティブなマップを組み合わせて軽減する MVP として制作しました。

## 主な機能

- 表記揺れを吸収するブース番号・サークル名の入力中検索
- サークル名の大文字小文字を区別しない部分一致検索
- A〜D エリア、通路、入口、出口、休憩スペースを備えた自作 SVG 会場マップ
- ブースのクリック・タップ・キーボード選択と選択位置へのスクロール
- マップの拡大・縮小・初期位置への復帰
- ブース詳細、頒布物、支払い方法、ダミー外部リンクの表示
- お気に入り・訪問済み状態の端末内保存とマップ上での識別
- ブース番号順のお気に入り一覧
- OS 設定に応じたライト・ダークテーマ

## 使用技術

- Vite 8
- React 19
- TypeScript 6
- Tailwind CSS 4 / `@tailwindcss/vite`
- Vitest
- SVG / localStorage
- GitHub Actions / GitHub Pages

バックエンドや外部 API は使用していません。

## ローカル起動方法

Node.js 24 と npm を用意し、次を実行します。

```bash
npm ci
npm run dev
```

## lint・テスト・ビルド

```bash
npm run lint
npm test
npm run build
```

## データと会場図

イベント、サークル、作品、人物、頒布物、価格などのデータはすべて架空です。実在イベントの公式マップや外部画像は使用せず、会場図とお品書き風プレースホルダーを SVG / CSS で自作しています。

## 現在の制限

- データは固定で、利用者による追加・編集はできません
- お気に入りと訪問済みは端末内にのみ保存され、端末間同期はありません
- マップは単一フロアで、ドラッグ操作やピンチズームには対応していません
- 検索対象はブース番号とサークル名のみです
- X と通販のリンクは動作確認用のダミーリンクです
